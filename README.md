# 星辰商城全栈平台

本仓库包含 Nuxt 4 前端与 Spring Boot 3 后端，已完成普通用户从商品浏览、购物车、下单到订单查询的闭环流程，同时保留后台管理模块（商品、订单、用户等）。

## 已完成内容

- **前端**：
  - 商城商品浏览（搜索、分类、分页、库存提示、数量选择）
  - 购物车管理（增删改查、数量校验、库存反馈）
  - 订单结算（选择地址、生成订单、模拟付款、成功反馈）
  - 我的订单（订单列表、收货信息、支付状态更新）
  - 后台控制台与商品/订单/用户管理页面体验优化
- **后端**：
  - 用户认证、个人资料、收货地址管理
  - 商品、购物车、订单领域服务与 REST 接口
  - 普通用户订单结算、历史查询与支付状态更新
  - 数据初始化脚本覆盖用户、商品、地址及演示订单

## 实验补强

- 新增 `payment_records` 与 `reviews` 两个实体，使系统实体总数达到 8 个
- 新增 `order_detail_view` 业务视图，用于封装订单详情联表查询
- 新增“用户消费与商品偏好统计查询”，满足多表连接、分组统计和窗口函数的复杂查询要求
- 在订单响应中新增支付摘要字段，便于前后端联调和实验演示
- 补充后端自动化测试，覆盖支付记录、评价一致性、视图和复杂查询

## 遇到的问题与解决方案（概览）

- Nuxt UI 升级后表格组件 API 变化导致后台多处列表显示 “No data”；重构为 `:data` 与 `#*-cell` 插槽后恢复正常。
- 订单弹窗状态管理不合理造成空白遮罩与可访问性告警；合并弹窗实例并延迟重置表单，解决闪屏问题。
- 新增订单结算时在后端使用 `forEach` 累加金额引起“变量需为最终变量”编译错误；改用增强 `for` 循环并同步扣减库存。
- `data.sql` 未能写入新订单收货字段；补充地址插入顺序和字段映射后生成的演示数据完整。
- 为满足数据库实验要求，额外补充了支付记录、商品评价、订单视图和复杂查询，并针对 H2/ PostgreSQL 差异补充了后端测试策略。

## 本地运行摘要

```bash
# 前端
cd nuxt-app
pnpm install
pnpm dev

# 后端
cd server
./gradlew clean build
./gradlew bootRun
```

默认前端运行在 `http://localhost:3000`，后端运行在 `http://localhost:8080`。前端通过 `NUXT_PUBLIC_API_BASE` 配置后端地址。

至此，商城业务功能和数据库实验补强均已完成，后续如需扩展（例如真实支付、物流跟踪等）可在现有模块基础上迭代。
