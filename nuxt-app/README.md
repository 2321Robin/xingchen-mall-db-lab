# 星辰商城前端（Nuxt 4）

本目录为星辰商城普通用户及后台管理界面的 Nuxt 4 前端，实现了商品浏览、购物车、订单结算等核心流程，并集成 @nuxt/ui 组件库完成统一的 UI 体验。

## 已完成功能

- 普通用户登录/注册与客户端会话管理，涵盖忘记密码流程
- 商品商城页：关键字搜索、分类筛选、分页、库存状态提示与数量选择加入购物车
- 购物车：新增/修改/删除/清空商品，数量合法性校验与库存同步
- 订单结算：收货地址选择、购物车确认、订单创建与支付状态更新
- 我的订单：展示个人订单列表、物流/金额信息及待付款订单的支付操作
- 后台管理：仪表盘、商品管理、订单管理、用户管理、管理员密码修改等

## 本地运行

```bash
pnpm install
pnpm dev
```

常用脚本：

- `pnpm lint`：运行 ESLint 校验
- `pnpm typecheck`：执行 Nuxt TypeScript 校验
- `pnpm build && pnpm preview`：构建并预览生产版本

默认开发地址为 `http://localhost:3000`。

## 接口与环境

前端通过 `runtimeConfig.public.apiBase` 与后端 Spring Boot 服务通信，默认值已在环境变量中配置。若后端地址变更，请在 `nuxt.config.ts` 或部署环境中的 `NUXT_PUBLIC_API_BASE` 做相应调整。

## 遇到的问题与解决方案

| 日期 | 问题 | 定位 | 解决方式 |
| ---- | ---- | ---- | -------- |
| 2025-11-10 | 商品、用户 UTable 始终显示 “No data” | 旧版 `:rows`/`#*-data` API | 迁移至 `:data` 与 `#*-cell` 插槽，表格恢复正常 |
| 2025-11-10 | 订单改价弹窗空白遮罩 | 重复渲染 `<UModal>` 并即时清空状态 | 重构弹窗状态机，补齐 `aria` 属性，消除闪屏 |
| 2025-11-10 | 修改密码页输入框拥挤 | 缺少布局容器与间距 | 引入网格布局与统一输入尺寸，提升可读性 |
| 2025-11-11 | 购物车数量可减至 0 | 缺少前端下限校验 | 在购物车与加入购物车逻辑中加入最小值限制 |
| 2025-11-11 | 结算页徽章触发 ESLint `member-delimiter-style` | 内联类型定义超出风格限制 | 抽出 `OrderStatusBadge` 类型，保持代码风格一致 |
